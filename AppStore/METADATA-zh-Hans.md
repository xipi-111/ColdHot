### 描述

ColdHot 是一款轻量、原生的 macOS 菜单栏性能监控工具。

点击菜单栏图标，即可在一个安静、清晰的面板里查看 Mac 当前的 CPU、GPU、内存、磁盘、网络、热状态和电池信息。一级指标保持简洁；每核心利用率、内存构成、网络数据包、电池健康等详细项由你主动勾选，并且只在对应卡片展开时采样。

主要功能：

• CPU 总使用率、系统负载与每核心利用率
• GPU 设备利用率与显示器信息
• 内存压力、内存构成与 Swap
• 磁盘容量、实时吞吐与 IOPS
• 网络接口、实时速度、数据包与累计流量
• macOS 系统热压力等级
• 电池电量、健康度、循环次数、剩余时间与电气信息
• 1 秒、2 秒或 5 秒刷新间隔
• 一级指标与详细项目独立选择并持久化

ColdHot 不创建账户，不包含广告或分析 SDK，也不会把监控结果上传给开发者或第三方。指标选择和界面偏好仅保存在你的 Mac 上。

Mac App Store 版本运行在 App Sandbox 中，并使用该版本允许的系统能力。部分依赖私有传感器或系统偏好修改的功能仅在官网版提供。

需要 macOS 14 或更高版本。

### 审核备注

ColdHot is a menu bar app and does not appear in the Dock. After launch, click the ColdHot gauge icon in the macOS menu bar to open the dashboard. No sign-in is required.

The Mac App Store build runs in App Sandbox and uses only the capabilities included in this edition. Private temperature/SMC sensors, cross-process rankings, Dock preference changes, and other direct-edition-only implementations are removed at compile time.

The optional network latency detail is off by default. If a user enables it and expands the Network card, the app opens a TCP connection to 1.1.1.1:443 about every 10 seconds only to measure connection latency. No monitoring data is sent.

ColdHot does not collect analytics, diagnostics, identifiers, usage data, or monitoring results. All displayed metrics and saved preferences remain on the Mac.
