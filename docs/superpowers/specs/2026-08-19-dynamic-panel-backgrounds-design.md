# ColdHot 动态菜单背景设计

**状态：** 已确认

**目标版本：** 1.4.0（20）

## 目标

在保留现有静态图片背景、裁切定位、遮罩和可读性设置的基础上，为菜单面板增加 GIF 与本地视频背景。动态媒体只在真实菜单面板或设置预览可见时播放，并为带音轨的视频提供明确、相互隔离的声音控制。

## 已确认范围

- 支持静态图片、GIF、MP4、MOV、M4V 及 macOS 可以解码的对应视频文件。
- GIF 导入后转换为无音轨的本地 MP4，视频保留原文件和音轨，不二次压缩。
- 静态图片、GIF 和视频共用现有缩放、拖动定位、方向键微调、深色遮罩、卡片透明度、文字亮度与进度条透明度设置。
- 实际菜单面板记住用户的视频声音选择；设置窗口使用独立的临时声音选择。
- 动态内容不可见时暂停，系统开启“减少动态效果”时只显示封面且不播放声音。
- 所有导入媒体只保存在本机，不上传。

## 非目标

- 不提供在线视频地址或网络流媒体背景。
- 不提供视频剪辑、截取、音量滑杆、播放速度、播放列表或多个背景轮换。
- 不重新压缩用户导入的视频，也不保证不受支持的容器或编解码器可以播放。
- 不为 GIF 添加声音。
- 不让设置预览的声音选择改变真实菜单面板的声音偏好。

## 选定方案

采用统一动态播放管线：GIF 在导入阶段转换为无音轨 MP4，原生视频保留源文件，二者运行时统一交给 AVFoundation 播放。

选择该方案的原因：

- 菜单每次打开时无需重新逐帧解码 GIF，资源占用更稳定。
- GIF 和视频共用循环、暂停、封面、减少动态效果及可见性控制。
- 视频不转码，避免导入等待、额外画质损失和大文件重复编码。

代价是 GIF 首次导入需要等待转换完成；视频的解码成本仍取决于源文件分辨率和编码，但只在界面可见时产生。

## 媒体模型

背景资源分为三类：

- `staticImage`：压缩后的 PNG，继续使用现有静态渲染路径。
- `convertedGIF`：由 GIF 转换得到的无音轨 MP4，加一张静态封面。
- `video`：复制到应用数据目录的原视频，加一张静态封面，并记录是否包含音轨。

应用层只消费一个背景资源描述，包含以下信息：

- 资源种类；
- 静态图片或封面；
- 动态媒体本地 URL；
- 是否包含可播放音轨；
- 原始统一类型标识和用于失效判断的资源版本。

旧版本留下的 `background.png` 在没有新元数据时继续按静态图片加载。用户无需手动迁移；首次成功更换背景后再进入新存储格式。

## 本地存储与事务

背景继续存放在：

`~/Library/Application Support/ColdHot/PanelBackground/`

新存储包含媒体文件、`poster.png` 和一份版本化元数据。导入过程遵循事务语义：

1. 在同一应用数据目录的临时位置读取、验证、转换或复制新资源。
2. 生成封面和完整元数据。
3. 全部成功后才原子切换当前元数据指向新资源。
4. 切换成功后清理旧媒体、旧封面和无引用临时文件。
5. 任一步骤失败时删除临时产物，继续使用原背景与原设置。

应用启动时清理未完成导入遗留的临时文件，但不得删除当前元数据引用的文件。移除背景时关闭播放、删除当前媒体与封面，并恢复现有背景位置和缩放默认值。

## 导入与转换

### 文件选择

设置页文案从“自定义图片”调整为“自定义背景”。文件选择器接受：

- PNG、JPEG、HEIC、TIFF 等现有静态图片；
- GIF；
- MP4、MOV、M4V 以及相应系统可播放视频类型。

### 大小限制

- GIF 最大 100 MB。
- 视频最大 1 GB。
- 不限制播放时长。
- 超出限制时在读取或复制大文件前拒绝导入，并保留原背景。

### GIF 转换

- 使用 ImageIO 读取完整帧序列和每帧时长，而不是只取第一帧。
- 尊重 GIF 的画布、方向和帧时序，并生成无限循环的无音轨 MP4。
- GIF 透明像素在编码前与其逻辑画布的背景色合成；文件未提供有效背景色时使用黑色，避免 MP4 不支持透明通道时产生未定义边缘。
- 最大像素边沿用现有 1,600 像素限制，超大 GIF 在转换时等比缩小。
- 无效或缺失的帧时长使用安全的最小时长，避免零时长帧造成异常解码负担。
- 封面取转换后首个有效视频帧。

### 视频导入

- 使用 AVFoundation 验证文件可播放且至少有一个视频轨道。
- 保留原始容器、编码、分辨率、帧率和音轨，不二次压缩。
- 复制到应用数据目录，运行时不依赖原文件或长期安全作用域权限。
- 记录是否存在可播放音轨；无音轨视频不显示声音控制。
- 封面取应用视频方向变换后的首个可用画面。

### 进度与错误

导入、复制或 GIF 转换期间，设置页显示“正在处理动态背景…”，禁用重复选择和移除操作。处理完成前，真实菜单和设置预览继续使用原背景。

错误文案应区分：

- GIF 超过 100 MB；
- 视频超过 1 GB；
- 文件损坏或无法读取；
- 没有视频轨道或当前 Mac 不支持该编码；
- GIF 转换失败；
- 本地存储空间或写入失败。

## 播放架构

动态媒体使用 `AVQueuePlayer` 与 `AVPlayerLooper` 无限循环。播放器与 SwiftUI 背景视图分离：

- 应用级菜单播放协调器服务真实菜单面板，使菜单关闭后仍可保留暂停位置与声音偏好。
- 设置预览使用独立播放协调器，不与真实菜单共享播放器、位置或静音状态。
- 背景渲染视图接收封面、动态媒体、是否应播放、静音和现有裁切参数。
- 播放未就绪、暂停、失败或被“减少动态效果”禁止时立即使用封面，不显示空白或闪烁。

视频画面继续使用现有 `PanelBackgroundTransform` 的铺满、缩放和位置结果。播放器层不得拦截菜单按钮、卡片或预览拖动手势。

## 可见性与资源策略

### 真实菜单面板

- 菜单出现且自定义背景启用时开始或继续播放。
- 菜单消失时立即暂停并移除活动视频输出，保留当前播放时间。
- 再次打开同一资源时从暂停位置继续。
- 更换或移除资源时销毁旧循环和旧播放状态。

### 设置窗口预览

- 只有设置窗口可见且当前标签为“外观”时播放。
- 离开“外观”标签、关闭设置窗口、更换或移除媒体时立即暂停，并把预览声音重置为静音。
- 重新进入“外观”标签时从静音状态开始。

### 减少动态效果

当系统“减少动态效果”开启时：

- 真实菜单和设置预览只显示静态封面；
- 播放器保持暂停，不进行动画解码；
- 不输出声音；
- 声音按钮保留但禁用，以解释当前状态且不改写用户原有菜单声音偏好。

提示位置：

- 真实菜单在底部栏上方显示克制提示“减少动态效果已开启”。
- 设置预览在声音按钮下方显示“减少动态效果已开启，动态背景与声音已暂停”。

提示仅在当前背景为动态媒体且系统确实开启减少动态效果时出现，不为静态图片长期占位。

## 声音状态

### 真实菜单面板

- 声音按钮放在底部“设置”按钮右侧。
- 仅带音轨的视频显示该按钮；静态图片、GIF 和无音轨视频隐藏。
- 按钮使用扬声器开/关图标、帮助文本和明确的辅助功能标签。
- 初始默认静音。
- 用户选择保存在 `UserDefaults`，菜单关闭、重新打开或应用重启后仍保留。
- 菜单关闭只暂停视频，不重置声音偏好。
- 导入或切换到另一段视频时自动把真实菜单声音偏好恢复为静音，避免新媒体突然出声。
- 减少动态效果开启时强制实际输出静音，但保留用户偏好；系统设置恢复后继续遵循此前选择。

### 设置预览

- 独立声音按钮位于“菜单面板真实范围”标题右侧。
- 仅带音轨的视频显示，默认静音。
- 用户可在本次外观预览中临时开启声音。
- 按钮下方提示“仅本次预览，离开后恢复静音”。
- 离开“外观”、关闭设置窗口、更换或移除媒体后恢复静音。
- 设置预览状态不写入 `UserDefaults`，也不修改真实菜单声音偏好。

## 界面调整

设置页背景区域根据当前资源显示“自定义图片”“动态 GIF”或“视频背景”，并把选择按钮统一改为“更换背景…”。无资源状态使用“选择背景…”，说明支持图片、GIF 与视频。

现有真实范围预览、拖动定位覆盖层和右侧调节项保持布局与含义。动态媒体封面和播放画面必须使用同一裁切参数，避免播放开始时位置跳变。

真实菜单底部新增声音按钮时不改变右侧风扇、采样间隔和退出信息的可读性；按钮与“设置”属于左侧操作组。减少动态效果提示位于内容与底部栏之间，采用现有辅助文字层级，不使用系统通知或横幅。

## 数据迁移与设置重置

- 现有静态背景、启用状态、裁切位置、缩放和可读性设置保持不变。
- 新增真实菜单声音偏好默认 `false`。
- 成功更换任意背景后继续复位位置和缩放。
- 成功更换为新视频后额外重置真实菜单声音为静音。
- 失败导入不改变资源、启用状态、裁切参数或声音偏好。
- “恢复默认设置”同时恢复声音偏好为静音，但不隐式删除背景文件，沿用现有设置重置与资源移除边界。

## 错误恢复

- 播放器运行时失败时暂停并回退到封面，界面仍可操作。
- 设置页在当前资源无法播放时显示本地错误提示，并允许用户更换或移除背景。
- 播放失败不得反复自动重建播放器造成高唤醒；只有资源变化或用户重新进入可见界面时进行有限重试。
- 应用异常退出后，下一次启动从已提交元数据恢复；不采用未提交临时文件。

## 测试与验收

### 自动检查

使用程序生成的小型测试媒体，避免测试依赖用户文件：

- 两帧不同颜色与不同时长的 GIF，验证完整帧时序、输出 MP4、无音轨和封面。
- 带音轨与无音轨的短视频，验证可播放性与音轨识别。
- 固定大小边界样本，验证 GIF 100 MB、视频 1 GB 的接受与拒绝边界。
- 故意损坏的图片、GIF 和视频，验证错误分类及原资源回滚。
- 旧 `background.png`，验证升级后仍正常加载。
- 背景资源切换，验证旧文件和临时文件清理。
- 纯状态策略测试，验证真实菜单声音持久化、换视频重置静音、设置预览离开重置、减少动态效果强制暂停与静音。
- 播放协调器测试，验证可见时播放、不可见时暂停、循环、同资源恢复位置和换资源销毁旧状态。
- 设置视觉检查覆盖声音按钮、两条提示、静态与动态状态，确保原 920×720 和 860×680 布局不溢出。

### 现场验收

- 导入 GIF 后能保持帧节奏循环播放，设置预览和真实菜单裁切一致。
- 导入带音轨视频后，真实菜单声音按钮位于“设置”右侧并能记住选择。
- 设置预览默认静音，可临时开启；切换标签或关闭再打开后恢复静音。
- 菜单关闭后视频与 GIF 立即暂停；再次打开同一资源继续播放。
- 开启系统减少动态效果后，两处仅显示封面、无声音，并出现对应提示。
- 静态图片、GIF 和无音轨视频不显示无效声音按钮。
- 失败或超限导入不会替换当前背景。

### 资源验收

- 菜单和设置预览都不可见时，播放器 `timeControlStatus` 为暂停且没有持续帧输出。
- 对比静态背景基线，菜单关闭后的 CPU 与唤醒不能出现持续动态解码增量。
- 菜单打开播放测试视频时记录 CPU、内存和唤醒，报告源视频规格，避免把单个样本结果泛化为所有视频。
- 长时间重复打开、关闭和更换媒体后，不遗留播放器、循环观察者、视频输出或临时文件。

## 发布

该功能改变用户可见能力，版本升级为 **1.4.0（20）**。先生成 Direct 本机测试包供安装验收；公开发布仍需在完整签名、公证、更新源和发行说明流程通过后单独执行。
