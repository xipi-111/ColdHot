# ColdHot 图标与面板可读性设计

## 目标

- 用用户照片中的手绘心电波形作为视觉灵感，替换当前偏复杂的风扇应用图标。
- 将自定义背景上的文字分为主文字、辅助文字两组，分别控制亮度/透明度。
- 将指标进度条作为第三组，独立控制透明度。
- 在设置页面直接展示接近真实菜单面板的实时预览。

## 已确认的视觉方向

- 图标采用浅色圆角底、深色手绘心电波形。
- 不保留原照片、纸张纹理、环境背景或文字。
- 风格克制，重点保证 16px 到 1024px 的清晰度。

## 面板角色

- 主文字：应用名称、指标名称、实时数值、详情分组标题、详情数值。
- 辅助文字：更新时间、指标说明、详情标签、状态说明、PID 和底栏文字。
- 进度条：指标卡片中的确定型进度条；加载中的不确定型进度指示保持系统行为。
- 自定义背景未启用时，三项透明度不改变系统默认外观。

## 设置与迁移

- 保留卡片不透明度。
- 新增主文字亮度、辅助文字亮度、进度条透明度三个滑杆，范围均为 50% 到 100%。
- 首次升级时，如果只有旧的 `panelTextOpacity`，将其值同时作为主文字和辅助文字的初始值。
- 重置设置时三项均恢复 100%。

## 实时预览

- 背景设置区域显示固定示例数据，不启动额外性能采样。
- 预览采用菜单面板真实 370px 宽画布，并根据当前启用指标数量和 Dock 快捷控制计算折叠状态高度；不使用与正式面板比例不同的横向图片缩略图。
- 背景图片使用与正式面板相同的 `scaledToFill` 与裁切边界，因此预览范围就是菜单面板实际能看到的图片范围。
- 预览包含顶部标题、当前启用指标的示例卡片、主/辅助文字、进度条和底栏。
- 预览直接复用生产环境的背景、卡片及可读性修饰器，拖动滑杆立即刷新。
- 预览对应用户每次点开菜单面板时的初始折叠状态；在正式面板中展开详情后，面板高度与背景裁切会随实际内容变化。
