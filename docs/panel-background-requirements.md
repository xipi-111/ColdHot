# ColdHot 自定义面板背景规格

## 目标

在 macOS 菜单栏点击 ColdHot 后，用户可以用自己选择的一张图片作为整个下拉面板的背景，并在不牺牲指标可读性或实时采样性能的前提下调节深色遮罩。

## 用户体验

- 设置页新增“面板背景”区域。
- 无图片时显示“选择图片…”按钮和仅保存在本机的说明。
- 导入成功后立即启用自定义背景，并显示预览、“更换图片…”和“移除背景”操作。
- 有图片时可以独立关闭或重新开启“使用自定义背景”。
- 深色遮罩可在 0%–70% 间调节，默认 35%。
- 背景覆盖整个下拉面板：顶部状态、指标列表、Dock 快捷控制和底部工具栏。
- 图片按比例自动裁切铺满；指标卡片保持半透明材质以保障可读性。
- “恢复默认”关闭自定义背景并把遮罩恢复到 35%，但保留已导入的本机副本；“移除背景”删除应用拥有的副本。

## 文件与隐私

- 仅支持单张可由 ImageIO 解码的系统图片格式，包括 PNG、JPEG、HEIC 和 TIFF。
- 导入时把图片最长边降采样到不超过 1600 px，并重新编码为 PNG，避免菜单面板持有原始超大图片和原始元数据。
- 副本存放在用户 Application Support 的 `ColdHot/PanelBackground/background.png`。
- ColdHot 不保留对原图路径的运行时依赖；原图移动或删除不影响面板背景。
- 图片和设置只在本机使用，不上传、不联网。

## 性能与容错

- 图片仅在导入或应用启动时解码，之后通过一个共享 `NSImage` 缓存在内存中。
- 指标刷新不会触发文件读取、图片缩放或重新编码。
- 导入失败不得覆盖现有有效背景。
- 缓存文件缺失或损坏时，面板自动回退到当前的 `regularMaterial` 背景。
- 图片状态变化和遮罩变化应立即反映在已打开或下次打开的菜单面板中。

## 发行范围

- 仅维护 `ColdHot Direct` 官网 / GitHub 分发版。
- 新功能版本号为 `1.2.0`，构建号为 `8`。
