# ColdHot 1.6.0

- 新增完整 English 界面，覆盖菜单面板、设置、指标详情、通知、隐私政策和无障碍提示。
- 支持简体中文与 English，默认跟随 macOS 语言，也可在「系统设置 → 通用 → 语言与地区 → 应用程序」中为 ColdHot 单独选择语言，重新打开应用后生效。
- 调整英文长文案在紧凑界面中的显示，并保留现有指标选择、阈值、自定义背景和其他偏好设置。

## English

- Added a complete English interface for the menu panel, settings, metric details, notifications, privacy policy, and accessibility descriptions.
- ColdHot now supports English and Simplified Chinese. It follows your macOS language preferences, or you can select a language specifically for ColdHot in System Settings → General → Language & Region → Applications. Relaunch ColdHot after changing its language.
- Refined English text for compact layouts. Existing metric selections, thresholds, custom backgrounds, and other preferences are preserved.
